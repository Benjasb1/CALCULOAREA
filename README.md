📝 Descripción del Proyecto
Programa desarrollado en C++ aplicando el enfoque modular y diseño Top-Down. Calcula el área de un círculo/diana a partir de un radio ingresado por el usuario, valida que el dato sea correcto mediante un filtro de consistencia y dibuja en consola una representación en arte ASCII según el tamaño del radio.
